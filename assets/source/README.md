# Source media

Do not commit an unlicensed or large source clip directly to normal Git history.

Member 1 will add a reproducible source record here containing:

- source title and URL or self-recorded statement;
- license/permission;
- local filename or fetch instructions;
- duration, resolution, frame rate, and audio information;
- SHA-256 checksum;
- any deterministic trim command.

The clip must be selected and frozen before ABR results are observed.
